# 🧮 لعبة مطابقة الأرقام (Number Matching Math Game)

لعبة تعليمية وتفاعلية مصممة للويب، تهدف إلى تنمية مهارات التفكير السريع وحل المعادلات الرياضية البسيطة بطريقة ممتعة وتنافسية عبر 10 مراحل متدرجة الصعوبة.

---

## ✨ المميزات الرئيسية

* **10 مراحل متدرجة:** تبدأ بالجمع البسيط وتتطور لتشمل الطرح والضرب مع زيادة تعقيد الأرقام تدريجياً.
* **نظام النقاط والقفل:** يحصل اللاعب على 10 نقاط في كل مرحلة (بإجمالي 100 نقطة للفوز الكامل)، مع نظام قفل للمراحل يتم فتحه تتابعياً وحفظ التقدم عبر `localStorage`.
* **مؤثرات صوتية برمجية (Web Audio API):** توليد أصوات تفاعلية للتوصيل، الفوز بالمرحلة، ومعزوفة انتصار خاصة للمرحلة النهائية بدون الحاجة لملفات خارجية أو مشاكل في التحميل.
* **احتفالات بصرية:** دمج مكتبة `Canvas-Confetti` لمؤثرات بصرية مذهلة عند الفوز باللعبة.
* **دعم PWA (تطبيق الويب التقدمي):** قابلة للتثبيت على الهواتف والأجهزة الذكية وتعمل بدون إنترنت (Offline).
* **تصميم عصري ومتجاوب:** مبنية بالكامل باستخدام **Bootstrap 5 (RTL)** مع بطاقات تفاعلية بتصميم عصري (Neumorphism & Smooth Shadows).
* **مشاركة الألعاب:** زر مشاركة مدمج يستغل واجهة المتصفح (`Web Share API`).

---

## 🛠️ التقنيات المستخدمة

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Bootstrap 5 (RTL Version)** لتصميم واجهة مستخدم متجاوبة.
* **Web Audio API** لتوليد الأصوات برمجياً.
* **SweetAlert2** للتنبيهات والرسائل التفاعلية.
* **Canvas Confetti** لمؤثرات الاحتفال.
